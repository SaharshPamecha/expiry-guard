Day 2/100 of building open-source DevOps tools:

Temporary Linux user accounts are a compliance nightmare.

Contractors need access. You create accounts. Six months later, stale accounts pile up and auditors ask uncomfortable questions.

I built expiry-guard to fix this.

🧵

Tweet 2/5
───
expiry-guard is a single Bash CLI for managing temporary user accounts:

→ create — Users with automatic expiry
→ audit — See all temp accounts with days remaining  
→ alert — Get notified before expiry
→ report — Generate compliance reports (HTML/JSON/CSV)

Zero dependencies. Any Linux distro.

Tweet 3/5
───
Usage example:

$ sudo expiry-guard create contractor-ux 2025-06-30
[✓] User created with expiry: 2025-06-30

$ sudo expiry-guard audit
USERNAME       EXPIRES      DAYS
contractor-ux  2025-06-30   117 ✓
temp-dev       2025-03-15   -5 ✗ EXPIRED

Colorized output. Machine-parseable. Built for production.
